## Overview

A responsive website for ARC, an architectural research collective focused on timeless design, innovative construction methods, and curated project presentation. Built with Astro, the site features a refined editorial-style layout, project-focused navigation, and a clean visual system that reflects the studio’s minimalist architectural identity.

## Contributions

- Designed and developed the website using Astro, HTML, TailwindCSS, and JavaScript.
- Created a structured multi-page experience for studio, project, and contact sections.
- Built responsive layouts and mobile navigation for smooth browsing across devices.
- Applied a clean architectural visual direction with strong typography, spacing, and imagery.
- Optimized the site structure for performance, readability, and portfolio presentation.

## Outcome

A polished studio website that clearly communicates ARC’s brand, values, and architectural portfolio through a modern and professional digital experience.
