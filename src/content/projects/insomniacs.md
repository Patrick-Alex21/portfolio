## Overview

Designed and developed solo in Unreal Engine 5 using Blueprints, with a focus on learning objectives, simulation systems, and user testing.

## Contributions

- Analysed and designed the learning objectives and game mechanics.
- Implemented the core systems and UI from start to finish.
- Integrated assets and audio, then performed functional testing.
- Conducted pre/post user testing and coordinated expert validation.

## Outcome

The prototype demonstrated measurable improvement in student understanding of insomnia through user testing and expert evaluation.
